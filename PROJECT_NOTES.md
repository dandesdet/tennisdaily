# Tennis Daily — общие заметки

## Решения редакции

- Ежедневный выпуск в @tennisdaily_uz запланирован на 07:00 по Ташкенту. Он освещает подтверждённые события предыдущего календарного дня. Перед отправкой проверяем историю канала.
- Утреннее задание Codex отправляет готовый выпуск через обновление `tg/teaser.txt` в `main`. GitHub Actions запускает Telegram teaser, результат проверяем по ответу Telegram и ссылке на пост. Ключ бота добавлен в GitHub, первая отправка ожидается.
- Новые ролики берём с YouTube-канала @dandesdet. Добавление на сайт пока ручное. У публикации должны быть своя дата и превью для ссылки.
- Одна карточка на локацию. Внутри карусель по типам кортов, свайп на телефоне и стрелки на компьютере. На мобильном тизеры в две колонки, с фото, названием и описанием изображения. В карточках типов кортов пока не показываем владельцев.
- На общем плане карты одна маленькая точка на локацию, без подписей. При приближении видны отдельные типы кортов и короткая подпись на локацию. Названия улиц скрыты. Фотометки достопримечательностей увеличиваются при наведении.
- По клику на достопримечательность открывается крупное фото. Подсказки кортов показывают количество по типам из поля `counts`, когда число известно.

## На перспективу

- Тренеры. Три демонстрационных фотокарточки показывают специализацию, пример стажа и оценки. По клику открывается профиль с описанием, примером отзыва, расписанием и пробной записью. Для реальной записи нужен общий сервер для сайта и Telegram-бота тренеров. Сайт показывает свободное и занятое время, тренер меняет своё расписание в боте. При брони бот показывает только назначенному тренеру имя, контактный телефон и возраст ученика. Сервер предотвращает двойную бронь одного слота.
- Платный видеоразбор. Игрок отправляет тренеру ролик. Из исходника выделяем короткие эпизоды с нужными движениями, убираем лишнее и даём тренеру замедленное воспроизведение. К каждому эпизоду тренер оставляет голосовой комментарий, текст или оба варианта. Игрок получает клипы вместе с комментариями к ним.
