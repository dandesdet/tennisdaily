# Tennis Daily — общие заметки

## Решения редакции

- Ежедневный выпуск в @tennisdaily_uz запланирован на 07:00 по Ташкенту. Он освещает подтверждённые события предыдущего календарного дня. Перед отправкой проверяем историю канала.
- Утреннее задание Codex отправляет готовый выпуск через обновление `tg/teaser.txt` в `main`. GitHub Actions запускает Telegram teaser, результат проверяем по ответу Telegram и ссылке на пост. Ключ бота работает: 13 ноября пост ушёл через GitHub (t.me/tennisdaily_uz/6). Отправлять только так. Скрипт `tg_channel.py` на Маке не запускать — 13 ноября он отправил устаревший пост от 7 ноября. Если картинки к посту нет — отправляем без неё, `tg/teaser.jpg` не держим.
- Новые ролики берём с YouTube-канала @dandesdet. Добавление на сайт пока ручное. У публикации должны быть своя дата и превью для ссылки.
- Одна карточка на локацию. Внутри карусель по типам кортов, свайп на телефоне и стрелки на компьютере. На мобильном тизеры в две колонки, с фото, названием и описанием изображения. В карточках типов кортов пока не показываем владельцев.
- На общем плане карты одна маленькая точка на локацию, без подписей. При приближении видны отдельные типы кортов и короткая подпись на локацию. Названия улиц скрыты. Фотометки достопримечательностей увеличиваются при наведении.
- По клику на достопримечательность открывается крупное фото. Подсказки кортов показывают количество по типам из поля `counts`, когда число известно.
- Самостоятельные ссылки получают область нажатия высотой от 44 px, пункты верхнего меню — от 56 px. Ссылки внутри абзацев получают небольшие отступы без наложения на соседние элементы.
- Форма «Знаете ещё корты?» открывает черновик сообщения редактору @dandesdet в Telegram. Посетитель подтверждает отправку в чате.
- Верхнее меню идёт в порядке разделов на странице. Прогноз из Open-Meteo в шапке показывает семь значков, короткие дни недели и дневные максимумы. Сегодня выделено плашкой.
- Цены на аренду. Для тарифов, зависящих от слота, ведём на страницу бронирования. Фиксированные суммы публикуем только с действующим первоисточником и датой проверки. При отсутствии подтверждения оставляем ссылку на бронирование или контакт площадки.

## Шаблон поста в канал (образец — выпуск 10 ноября, t.me/tennisdaily_uz/4)

```
🎾 <b>Tennis Daily · 10 ноября</b>

<b>Лид пункта.</b> Одна-две фразы по делу. <a href="…">Ссылка на источник</a>

(3–5 пунктов, между ними пустая строка)

Больше анонсов, результатов и карта кортов → <a href="https://tennisdaily.uz">Tennis Daily</a>
Есть новость? → @dandesdet
```

- Шапка: только дата выпуска по Ташкенту, без дня недели.
- Даты в пунктах: «Сегодня», «Завтра» для N и N+1, всегда плюс короткий день недели и дата: «Завтра, сб 14 ноября», «Вс 15 ноября».
- Без картинок и без превью ссылки (превью отключает workflow). Ссылка на первоисточник — внутри пункта.
- Последние две строки всегда одни и те же (ссылка на сайт и «Есть новость? → @dandesdet»).

## На перспективу

- Тренеры. Три демонстрационных фотокарточки показывают специализацию, пример стажа и оценки. По клику открывается профиль с описанием, примером отзыва, расписанием и пробной записью. Для реальной записи нужен общий сервер для сайта и Telegram-бота тренеров. Сайт показывает свободное и занятое время, тренер меняет своё расписание в боте. При брони бот показывает только назначенному тренеру имя, контактный телефон и возраст ученика. Сервер предотвращает двойную бронь одного слота.
- Платный видеоразбор. Игрок отправляет тренеру ролик. Из исходника выделяем короткие эпизоды с нужными движениями, убираем лишнее и даём тренеру замедленное воспроизведение. К каждому эпизоду тренер оставляет голосовой комментарий, текст или оба варианта. Игрок получает клипы вместе с комментариями к ним.
